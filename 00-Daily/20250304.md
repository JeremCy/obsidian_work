## Ongoing Tasks
Pour configurer un nouveau nom de domaine pour vos e-mails chez OVH et rediriger les e-mails de votre ancien domaine vers le nouveau, suivez les étapes suivantes :

### 1. **Ajouter le Nouveau Domaine à Votre Hébergement de Messagerie**

- **Si vous disposez déjà d'un service de messagerie chez OVH (comme MX Plan) :**
    
    - Connectez-vous à votre espace client OVHcloud.
    - Dans le menu de gauche, cliquez sur **"Emails"**.
    - Sélectionnez votre service de messagerie existant.
    - Recherchez une option pour ajouter un domaine à ce service. Si cette option n'est pas disponible, il peut être nécessaire de souscrire à un nouveau plan de messagerie pour le nouveau domaine.
- **Si vous n'avez pas encore de service de messagerie pour le nouveau domaine :**
    
    - Vous devrez souscrire à une offre de messagerie pour ce domaine. OVH propose des solutions comme **MX Plan** ou **Email Pro**.
    - Après souscription, associez le nouveau domaine à ce service en suivant les instructions fournies par OVH.

### 2. **Créer des Adresses E-mail sur le Nouveau Domaine**

- Une fois le nouveau domaine associé à votre service de messagerie :
    - Dans votre espace client OVHcloud, allez dans **"Emails"** puis sélectionnez le service lié à votre nouveau domaine.
    - Cliquez sur **"Créer une adresse e-mail"**.
    - Définissez les adresses e-mail souhaitées (par exemple, [contact@nouveaudomaine.com](mailto:contact@nouveaudomaine.com)).

### 3. **Configurer la Redirection des E-mails de l'Ancien Domaine vers le Nouveau**

- Dans votre espace client OVHcloud :
    - Allez dans **"Emails"** et sélectionnez le service de messagerie associé à votre ancien domaine.
    - Accédez à l'onglet **"Redirections"**.
    - Cliquez sur **"Ajouter une redirection"**.
    - Pour chaque adresse e-mail de l'ancien domaine, configurez une redirection vers l'adresse correspondante du nouveau domaine (par exemple, rediriger [contact@anciennentdomaine.com](mailto:contact@anciennentdomaine.com) vers [contact@nouveaudomaine.com](mailto:contact@nouveaudomaine.com)).

### 4. **Mettre à Jour les Enregistrements DNS du Nouveau Domaine**

- Pour assurer le bon fonctionnement de la messagerie sur le nouveau domaine :
    - Dans votre espace client OVHcloud, allez dans **"Domaines"**.
    - Sélectionnez votre nouveau domaine.
    - Accédez à l'onglet **"Zone DNS"**.
    - Vérifiez que les enregistrements **MX** pointent vers les serveurs de messagerie d'OVH (par exemple, mx1.mail.ovh.net, mx2.mail.ovh.net, mx3.mail.ovh.net).
    - Si votre domaine est géré par un autre fournisseur, assurez-vous que les enregistrements MX sont correctement configurés chez ce fournisseur.

### 5. **Tester la Configuration**

- Envoyez des e-mails tests à vos anciennes adresses pour vérifier qu'ils sont bien redirigés vers les nouvelles adresses.
- Assurez-vous également que l'envoi d'e-mails depuis les nouvelles adresses fonctionne correctement.
